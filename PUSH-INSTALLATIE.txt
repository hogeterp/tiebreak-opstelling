PUSHMELDINGEN – VERSIE 2.3.7

De gewone webapp kan zonder map functions naar GitHub worden geüpload.

IN DE APP:
1. Open Firebase Console > Projectinstellingen > Cloud Messaging.
2. Maak bij Web Push-certificaten een sleutelpaar.
3. Kopieer de openbare VAPID-sleutel.
4. Open de webapp als organisator > Beheer > Pushmeldingen.
5. Plak de VAPID-sleutel, sla hem op en druk op Meldingen inschakelen.

EENMALIGE TECHNISCHE STAP:
Voor het werkelijk versturen van een melding moet de Firebase Cloud Function één keer apart naar Firebase worden gepubliceerd. Gebruik vanaf v2.3.6 het aparte pakket Firebase-backend-v2.3.6.zip. Dit pakket bevat ook de veilige organisatorlogin en archiefsync. Deze bestanden hoeven niet naar GitHub Pages.
